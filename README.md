Dify获取图片URL，调用YOLO接口：`http://host.docker.internal:8001/detect_by_url`；3. YOLO返回检测到的物体类别数组；4. 将物体列表送入Ollama本地大模型；5. 大模型输出场景判断、场景描述、实用提示，支持用户继续提问。## 环境依赖```bashpip install fastapi uvicorn ultralytics requests运行步骤1. 将训练好的 best.pt 放到项目根目录；2. 启动 YOLO 推理服务uvicorn main:app --host 0.0.0.0 --port 8001启动 Ollama，拉起所需本地大模型；4. 启动 Docker 版 Dify，导入配置完成的工作流，绑定 Ollama 模型提供者；5. 在 Dify 对话页面上传图片即可测试。关于进阶任务 4 HarnessHarness 属于选做进阶任务。我尝试把 YOLO 推理服务容器化作为 Harness 组件，目标是接入 Dify 的 Docker 网络，规避宿主机访问问题。调试过程反复遇到 OpenCV 动态链接库缺失、各类包依赖冲突，尝试更换基础镜像、opencv‑headless、xvfb 虚拟显示等方案仍无法稳定运行。权衡时间成本，优先保障任务 1、任务 2、创意作品完整可用，全部踩坑过程记录在 worklog.md。仓库文件说明• main.py：YOLO FastAPI 后端推理接口，精简输出，只返回物体类别；• worklog.md：工程日志，记录开发过程、报错现象、排查思路与方案取舍；• assets/demo.png：项目运行演示截图；• .gitignore：屏蔽模型权重、python 缓存、环境文件，保持仓库干净。
